# Botanical Garden 3D Viewer

Visor 3D interactivo inspirado en **LEGO Ideas The Botanical Garden (21353)**, construido con HTML, CSS y Three.js.

## Ejecutar

Abre `index.html` en un navegador moderno. También puedes publicarlo con GitHub Pages.

## Controles

- Arrastra para orbitar la cámara.
- Usa la rueda o el gesto de pellizco para hacer zoom.
- Retira los techos para explorar el interior.
- Cambia entre iluminación victoriana y modo neón.
- Activa la rotación automática o selecciona una vista predefinida.
